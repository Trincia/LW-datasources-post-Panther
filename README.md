# LW-datasources-post-Panther

Dark-mode Lakewatch prototype for the post-Panther datasource and schema experience.

Built on the [Databricks UI Starter Kit](https://github.com/gioa/db-starter-kit) with DuBois design system components and Figma-aligned Lakewatch chrome.

## Prototype routes

| Screen | Route |
|--------|-------|
| Datasources list | `/lakewatch/datasources` |
| Add datasource | `/lakewatch/datasources/new` |
| Overview (placeholder) | `/lakewatch` |

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000/lakewatch/datasources](http://localhost:3000/lakewatch/datasources).
